# Web & Mobile Applications

This directory contains client-facing applications for the Vitalis supply chain platform:

- **[web/](./web)**: Next.js Command Center & Admin Console (network topology mapping, inventory dashboards, Human-in-the-Loop dispatch approvals).
- **[mobile/](./mobile)**: React Native / Expo Courier Application (driver turn-by-turn logistics, barcode scanning, IoT cold-chain temperature telemetry prompts).
