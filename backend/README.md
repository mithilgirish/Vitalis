# Backend Service (FastAPI & LangChain)

This directory houses the core backend services, orchestrations, and REST API for Vitalis.

## Structure

- **[api/](./api)**: FastAPI REST endpoints, request validation, authentication, and router controllers.
- **[agent/](./agent)**: LangChain ReAct agent logic, Text-to-SQL tools, viability routing calculations, and depletion guardrails.
